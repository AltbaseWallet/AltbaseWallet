LIMITS AND SAFETY BOUNDARIES
No new macOS binary exists. The concrete blocker remains an unstaged compatible
Darwin vault toolchain (darwin-arm64), plugin-host/account-module compiler and SDK.
macOS continues to link to the actual older 0.1.9 release.
The upstream elliptic advisory remains visible to npm audit; the local correction,
reachable BitGo/CKB/JoyID/Nexa calls and public offline vectors are documented in
CRYPTO-AUDIT-2026-09-24.md. Passing tests do not imply zero upstream advisories.
PublicNode restrictions still prevent complete historical/token discovery for
some networks. A failed/restricted read is not a zero balance. External icon
sources can lack an arbitrary token image; the deterministic fallback remains.
The native-coin feed does not provide market prices for every arbitrary token.
Unreachable legacy Nonsense relays concern a delisted, separate network and are
not represented as an operational current-wallet network.
The native Windows installer test used an administrative image, preserving the
running user installation; normal install/uninstall was checked separately under
Wine. No native in-place upgrade of the real user installation is claimed.
The earlier unreleased local 0.1.13 build with the null update-check stub
cannot repair its own checker and must be replaced manually once using the
corrected MSI or portable ZIP. Public older releases with the original working
checker can receive the new backend notification.
No real user phrase was printed, saved in evidence or used for these tests. No
real user transfer was signed, sent, confirmed, repeated or moved between wallets.
The tests cover the exercised fixtures and live reads, not every future provider,
consensus or hardware condition.
