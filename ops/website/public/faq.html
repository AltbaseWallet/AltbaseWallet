Altbase Wallet is a non-custodial desktop wallet. It creates and stores wallet data locally, then connects to supported networks so users can view balances and prepare transactions.
Wallet creation does not require an account, identity verification or KYC. Users should still follow good privacy practices when transacting on public blockchains.
Private keys and backup phrases are stored only on the user's device. Altbase Wallet does not collect, transmit or keep a copy of them.
A backup phrase is the master recovery key for a wallet. Anyone who has it can access the funds, so it should be stored offline and never shared.
