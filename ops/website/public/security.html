Security model

Your wallet, your keys, your device.

Altbase Wallet is designed as a non-custodial interface. Sensitive data is encrypted locally and never leaves the user's device.

SelfUser-controlled custody

Private keys stay local

Altbase Wallet does not receive private keys, backup phrases or passwords. The wallet data belongs to the user and remains on the user's computer.

Encrypted wallet data

Wallet files are protected by local encryption. A strong password and offline backup phrase storage are recommended for every user.

No account layer

Users can create a wallet without email registration or identity verification. There is no hosted account that controls funds.

Blockchain-based balances

Funds are held on their respective blockchains. Altbase Wallet provides an interface for viewing balances and creating transactions.

Privacy

Minimal data by design.

Altbase Wallet does not store user private keys, backup phrases, passwords or identity documents. Users are responsible for keeping their backup phrase offline and secure.

Terms

Use the wallet responsibly.

Digital asset transactions are irreversible. Always verify addresses, download files from trusted sources and check release hashsums before installing.

Risk notice

Self-custody requires care.

If a backup phrase is lost, funds may be unrecoverable. If a backup phrase is shared, funds can be stolen. Altbase support will never ask for your backup phrase.
