Altbase Wallet 0.1.13

What changed in 0.1.13

35 active networks with runtime coin modules and network tokens.

1

ETH, BSC, Polygon, Arbitrum, Solana and Tron support manual token import, on-demand icons and hidden spam.

2

PEARL pending balances and MAX, Xelis broadcast recovery, EPIC receiving during scans, and independent price refresh are corrected.

3

Coin modules load from one common folder without rebuilding the wallet. Locally modified unsigned Mining modules are supported.

4

Application update notices are restored. Windows MSI/ZIP, Linux x64 TAR.GZ and universal macOS ZIP are available for 0.1.13.

HRC, MYDOGE, NNN and BTGS are delisted in 0.1.13. Use an older wallet version if you need these coins.
