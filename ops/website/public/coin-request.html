Asset support

Request a coin listing.

Submit project details for review. Approved requests are evaluated for wallet integration, market availability and long-term maintenance.

Before applying

Only submit assets with active trading, public market data and enough project information for technical review.

Requirements

Minimum listing conditions

Exchange tradingThe coin must be actively traded on an exchange with at least $1,000 in volume.
Market aggregatorThe coin must be listed on at least one aggregator such as CoinMarketCap, CoinGecko, LiveCoinWatch or CoinPaprika.
ANN post after listingAfter the coin is added to Altbase Wallet, the project must publish a post in its own official ANN thread announcing wallet support.
Public project dataSubmit the official website, explorer, source repository and exchange market link when available.
Technical reviewWallet integration depends on network stability, node availability, build requirements and maintenance status.
